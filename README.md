# Carrara — Studio &amp; Journal

An editorial website designed in the spirit of premium fashion magazines and art publications.

Warm ivory paper, deep burgundy, espresso, muted gold and charcoal. Fraunces serif display type paired with Archivo. Slow, expensive-feeling motion — image reveal masks, line-based text reveals, a horizontal image band that moves with scroll, and a following-image archive list.

## Pages

- `index.html` — Cover / masthead
- `journal.html` — The archive (following-image list)
- `story.html` — The Feature (long-form essay)
- `about.html` — Studio manifesto

## Structure

- `assets/css/main.css` — design system
- `assets/js/main.js` — nav, reveals, parallax, transitions
- Photography via images.unsplash.com

## Deploy

Static site. Push to GitHub and import into Vercel — no build step required.
